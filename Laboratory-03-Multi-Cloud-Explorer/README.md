# Laboratory 03 – Multi-Cloud Explorer

## Mission Overview

This laboratory activity explores and compares three major cloud computing platforms:

- Amazon Web Services (AWS)
- Microsoft Azure
- Google Cloud Platform (GCP)

The activity evaluates their services, advantages, use cases, and suitability for different business requirements.

## Cloud Platforms

- AWS
- Microsoft Azure
- Google Cloud Platform

## Activities

1. Explore AWS
2. Explore Microsoft Azure
3. Explore Google Cloud Platform
4. Compare cloud platforms
5. Recommend platforms for different clients
6. Match equivalent cloud services
7. Investigate a Linux server using KillerCoda
8. Write a mission reflection
