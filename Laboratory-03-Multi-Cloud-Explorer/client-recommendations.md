# Checkpoint 4 – Cloud Platform Recommendation Challenges

## Client A – Startup Company

### Recommended Platform: AWS

AWS is recommended because it provides many cloud services that can support a startup with a limited budget. The company can start with small resources and increase them as the mobile application grows. AWS also provides many services that can support application development, storage, and databases. This makes it suitable for a startup expecting rapid growth.

**Recommended Services:**

* Amazon EC2 – Application computing
* Amazon S3 – Data and file storage
* Amazon RDS – Managed database

---

## Client B – University

### Recommended Platform: Microsoft Azure

Microsoft Azure is recommended because the university already uses Windows Server, Microsoft 365, and Active Directory. Azure provides strong integration with Microsoft's existing technologies, making cloud migration easier. The university can also manage users, applications, and virtual machines through Azure. This makes Azure a suitable choice for the university's existing environment.

**Recommended Services:**

* Azure Virtual Machines – Windows Server workloads
* Microsoft Entra ID – Identity and access management
* Azure Blob Storage – Cloud storage

---

## Client C – AI Research Company

### Recommended Platform: Google Cloud Platform (GCP)

Google Cloud Platform is recommended because the company focuses on Artificial Intelligence and Machine Learning. GCP provides cloud infrastructure that can support high-performance computing and AI workloads. It also provides services for machine learning and containerized applications. These capabilities make GCP a strong choice for an AI research company.

**Recommended Services:**

* Compute Engine – High-performance computing
* Google Kubernetes Engine (GKE) – Containerized applications
* Vertex AI – AI and Machine Learning development

---

## Client D – Global E-Commerce Company

### Recommended Platform: AWS

AWS is recommended because the company needs highly available infrastructure and automatic scaling for customers around the world. AWS provides global infrastructure that can support applications across different regions. Its computing, database, and scaling services can help the company handle changing customer demand. This makes AWS suitable for a large global e-commerce platform.

**Recommended Services:**

* Amazon EC2 – Application servers
* Amazon S3 – Storage
* Amazon RDS – Database management
* Elastic Load Balancing – Distributes application traffic
* Amazon EC2 Auto Scaling – Automatically adjusts computing capacity
