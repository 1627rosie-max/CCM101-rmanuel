# Laboratory 01 – Welcome to the Cloud

## Mission Overview

This laboratory introduces the fundamentals of cloud computing and Linux command-line operations using the KillerCoda Playground.

## Objectives

- Understand the basic concepts of cloud computing.
- Practice using the Linux terminal.
- Create and manage directories and files.
- Use basic Linux commands.
- Document the activities performed during the laboratory.

## Activities Performed

- Accessed the KillerCoda Playground.
- Opened and used the Linux terminal.
- Created the required directory structure.
- Created and managed files using Linux commands.
- Configured Git with my GitHub identity.
- Initialized and managed a Git repository.
- Documented the laboratory activities.

## Linux Commands Used

- `pwd` – Displays the current working directory.
- `ls` – Lists files and directories.
- `cd` – Changes the current directory.
- `mkdir` – Creates a directory.
- `touch` – Creates a file.
- `echo` – Writes text to a file.
- `cat` – Displays file contents.
- `git init` – Initializes a Git repository.
- `git status` – Shows the current Git status.
- `git add` – Adds files to the staging area.
- `git commit` – Creates a Git commit.
