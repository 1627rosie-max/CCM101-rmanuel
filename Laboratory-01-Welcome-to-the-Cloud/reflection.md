# Reflection

## My Learning Experience

This laboratory activity helped me understand the basic concepts of cloud
computing and Linux command-line operations. Using the KillerCoda Playground
allowed me to practice Linux commands in a real cloud-based environment.

At first, some commands were unfamiliar to me, and I made a few typing
mistakes. However, by checking the error messages and trying the commands
again, I was able to understand how the Linux terminal works.

## What I Learned

I learned how to navigate directories, create files and folders, check
system information, and use basic Linux commands. I also learned the
importance of Git and GitHub for managing and documenting projects.

## Challenges Encountered

One of the challenges I encountered was remembering the correct syntax of
Linux commands. I also experienced errors when entering some commands.
These challenges helped me become more careful when typing commands and
reading terminal error messages.

## Overall Reflection

Overall, this laboratory was a useful hands-on experience. It improved my
confidence in using the Linux terminal and introduced me to working with
cloud-based environments. I also learned that making mistakes is part of
the learning process, and understanding error messages can help solve
problems more effectively.

I believe the skills I gained from this activity will be useful in future
cloud computing, networking, and IT projects.
