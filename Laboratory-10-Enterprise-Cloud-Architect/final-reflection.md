# Final Reflection

## What We Learned

This project helped us understand how Ubuntu Server, Docker,
Docker Compose, WordPress, MySQL, networking, firewall security,
persistent storage, and automated backups work together.

We learned how to deploy and manage containers, configure
persistent Docker volumes, secure the server using UFW, and
automate database backups using Bash and Cron.

## Challenges and Solutions

Our group encountered challenges with Docker configuration,
container networking, firewall settings, and backup automation.

We solved these challenges through testing, troubleshooting,
checking logs, and verifying each component of the system.

## Project Outcome

We successfully deployed a WordPress and MySQL application
using Docker Compose. We also verified persistent storage,
firewall protection, and automated database backups.

This project improved our understanding of cloud infrastructure,
containerization, security, and automation.

## AI Assistance

AI tools were used to assist with troubleshooting,
clarification, and documentation. The system configuration,
testing, and implementation were performed and verified
by our group.
