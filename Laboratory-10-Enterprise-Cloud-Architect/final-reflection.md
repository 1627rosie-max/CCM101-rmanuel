## Final Reflection

## What We Learned

This project helped us understand how Ubuntu Server, Docker, Docker Compose, WordPress, MySQL, networking, firewall security, persistent storage, and automated backups work together as a complete system. We learned how to deploy and manage containers, configure persistent Docker volumes to preserve data, secure the server using UFW with a default-deny policy, and automate database backups using Bash scripts and Cron scheduling.

Completing this project has been a meaningful journey from the basics of cloud computing to building a fully functional enterprise-ready infrastructure. From setting up a virtual machine and learning Linux commands to deploying a multi-tier application with Docker Compose, every step taught us the value of structure, security, and automation.

We realized that cloud computing is not just about running applications — it is about protecting data, ensuring services stay available, and making systems maintainable. Configuring UFW firewalls taught us how to secure access; writing backup scripts and scheduling them with Cron showed us how to build reliability into our work; and using persistent volumes made us understand why data protection matters.

## Challenges and Solutions

Our group encountered challenges with Docker configuration, container networking, firewall rules, and backup scheduling. There were hurdles from debugging container connections to ensuring backups ran automatically — but solving them helped us shift from simply following instructions to thinking like system architects. We resolved these issues through systematic testing, reviewing logs, verifying port mappings, and confirming service status at each step. We double-checked that MySQL runs only on the internal Docker network and that persistent volumes remain intact to prevent data loss. This project showed us that a strong foundation, clear documentation, and attention to detail are what make a system truly ready for real-world use.

## Project Outcome

We successfully deployed a secure, multi-tier WordPress and MySQL application using Docker Compose on Ubuntu Server. The system includes verified persistent storage, UFW firewall protection with only necessary ports open, and scheduled daily backups. This project strengthened our practical skills in cloud infrastructure, containerization, system security, and operational automation. As future IT professionals, we carry forward not just technical skills, but the discipline of building secure, automated, and well-documented systems that serve users reliably.
